# UI Tests for Stellarburgers (QA)

Автотесты для сайта https://qa-stellarburgers.education-services.ru/ написанные с использованием Selenium WebDriver и pytest.

## Структура проекта

```
.
├── conftest.py              # Фикстуры pytest и WebDriver Factory
├── requirements.txt         # Зависимости проекта
├── data/                    # Данные и константы
│   ├── __init__.py
│   └── urls.py              # URL-адреса (BASE_URL, BASE_API_URL)
├── pages/                   # Page Objects
│   ├── __init__.py
│   ├── base_page.py         # Базовый класс для всех страниц
│   ├── login_page.py        # Страница входа
│   ├── forgot_password_page.py  # Страница восстановления пароля
│   ├── profile_page.py      # Страница профиля
│   ├── constructor_page.py  # Страница конструктора (главная)
│   └── orders_feed_page.py  # Страница ленты заказов
├── locators/                # Локаторы элементов
│   ├── __init__.py
│   ├── common_locators.py   # Общие локаторы
│   ├── login_locators.py    # Локаторы страницы входа
│   ├── forgot_password_locators.py  # Локаторы восстановления пароля
│   ├── profile_locators.py  # Локаторы профиля
│   ├── constructor_locators.py  # Локаторы конструктора
│   └── orders_feed_locators.py  # Локаторы ленты заказов
└── tests/                   # Тесты
    ├── __init__.py
    ├── test_forgot_password.py  # Тесты восстановления пароля
    ├── test_profile.py          # Тесты личного кабинета
    ├── test_constructor.py      # Тесты конструктора
    └── test_orders_feed.py      # Тесты ленты заказов
```

## Паттерн Page Object Model

Проект использует паттерн Page Object Model (POM) для организации тестов:

- **BasePage** (`pages/base_page.py`) - базовый класс с общими методами для работы с элементами
- **Страницы** - каждый класс страницы наследуется от BasePage и содержит методы для взаимодействия с элементами этой страницы
- **Локаторы** - вынесены в отдельный пакет `locators/` для удобного управления

## Установка

```bash
pip install -r requirements.txt
```

## Запуск тестов

```bash
pytest tests/ -v
```

### Запуск конкретного теста:
```bash
pytest tests/test_forgot_password.py -v
```

## Описание тестов

### Восстановление пароля (`test_forgot_password.py`)
- Переход на страницу восстановления пароля по кнопке «Восстановить пароль»
- Ввод почты и клик по кнопке «Восстановить»
- Проверка активности поля при клике на кнопку показать/скрыть пароль

### Личный кабинет (`test_profile.py`)
- Переход по клику на «Личный кабинет»
- Переход в раздел «История заказов»
- Выход из аккаунта

### Проверка основного функционала (`test_constructor.py`)
- Переход по клику на «Конструктор»
- Переход по клику на «Лента заказов»
- Открытие всплывающего окна с деталями ингредиента
- Закрытие всплывающего окна кликом по крестику
- Увеличение каунтера ингредиента при добавлении
- Оформление заказа залогиненным пользователем

### Лента заказов (`test_orders_feed.py`)
- Открытие всплывающего окна с деталями заказа
- Отображение заказов пользователя из истории в ленте
- Увеличение счётчика «Выполнено за всё время»
- Увеличение счётчика «Выполнено за сегодня»
- Появление номера заказа в разделе «В работе»
